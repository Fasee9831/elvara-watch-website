# ÉLVARA — Manufacture de Haute Horlogerie ⌚✨

> An ultra-luxury digital atelier and interactive storytelling experience for handcrafted Haute Horlogerie timepieces.

---

## 🌟 Highlights & Features

- **🎬 Cinematic Frame-by-Frame Scroll Scrubbing**: Scroll-driven 180-frame canvas animations showcasing openworked watch calibres and exploded mechanical movements.
- **✨ Gold Stardust Particle Preloader**: A bespoke canvas-rendered particle logo reveal with realistic luxury shimmer and lighting.
- **📜 Pinned Chapter-by-Chapter Storytelling**: Fluid, cinematic scroll choreography with live telemetry, craft specs, and typography reveals powered by GSAP ScrollTrigger & Lenis.
- **🎨 Interactive 3D Watch Customizer**: Personalize cases (18K Rose Gold, DLC Obsidian Titanium, Platinum), dial bezels, and handcrafted alligator straps with real-time price calculation.
- **⚖️ Side-by-Side Watch Comparator**: Interactive tool to compare technical dimensions, jewel counts, power reserves, and water resistance.
- **💱 Global Multi-Currency Support**: Instant currency conversion across INR, USD, EUR, GBP, CHF, JPY, CAD, AUD, SGD, and AED.
- **📱 Fully Responsive & Fast**: Optimized for 60fps rendering across desktop, tablets, and mobile devices.

---

## 🛠️ Built With

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS + Custom Horlogerie Design Tokens
- **Animations**: GSAP, ScrollTrigger, Lenis Smooth Scroll
- **Visuals**: HTML5 2D Canvas, WebP Image Sequences, Hardware-Accelerated Video

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/elvara-watch.git
cd elvara-watch
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.

### 4. Build for production
```bash
npm run build
```
